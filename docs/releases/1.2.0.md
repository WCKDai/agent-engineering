# eng 1.2.0

## Changes

- CLI: `verify --profile nightly`; `scope` and `duration_s` in every record; optional `run`, `cost`
  and `cache` fields; an opt-in independent-verification gate; flaky-test quarantine with owner and
  expiry; `eng digest` for exception-only reporting across repositories.
- Seven new skills and an extended failure-investigator; four build paths; three principles;
  delivery metric definitions; failure modes and new conditional/candidate entries in the catalog.

## Compatibility

- `eng-evidence/v1` is extended additively. New fields are optional for consumers; 1.1.x records
  verify unchanged. `eng-quarantine/v1` and `eng-digest/v1` are new identifiers.
- Existing subcommands, flags and exit codes keep their meaning. `--profile` gains `nightly`.
- Skill names and directories of the ten existing skills are unchanged.

## Verification

See the pull request for the commands run and the evidence record.

## Limits

No new tool is adopted: the catalog additions are conditional or candidate and none has been
exercised at fleet scale. Identities are declared, not authenticated. The digest reads local files.
