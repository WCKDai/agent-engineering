# eng 1.3.0

## Changes

- Eight new skills generalized from OpenCode, t3code, Sentry, Twenty and Temporal: safe-migrations,
  compatibility-and-deprecation, progressive-delivery, test-design, diff-hygiene,
  pull-request-craft, behavior-review and agent-guidance. Each cites its pinned sources.
- `verification-tiers`: change-scoped test selection fails open, and files with global effect
  always trigger the full suite.
- `contract-guardian`: one set of change classes; migration rollback follows safe-migrations;
  deploy order and deprecation timelines move to compatibility-and-deprecation.
- `references/inspiration.md` credits the five projects and the revisions read.
- Build paths "Add a feature" and "Prepare a release" point at the new skills.

## Compatibility

- No CLI, schema, flag or exit-code change. Existing skill names and directories are unchanged.
- Harnesses that load every skill see eight more descriptions.

## Verification

See the pull request for the commands run and the evidence record.

## Limits

The skills are guidance read from other projects' source; no WCKD repository has exercised them
yet.
